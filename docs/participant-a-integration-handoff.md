# Интеграция интерфейса A с серверной основой B

Дата: 2026-10-14. Ветка: `feat/a-integration-root`. Основа: `stage-3/b-market-data`; история A0–A4 объединена merge-коммитом.

## Что объединено

- Единственное приложение Next.js теперь расположено в корне репозитория: экраны A перенесены в `src/app`, компоненты в `src/components`, справочные записи в `src/lib`. Серверные маршруты B в `src/app/api` сохранены.
- Зависимости интерфейса объединены с корневым `package-lock.json`. Настройки Tailwind/Turbopack совмещены с заголовками безопасности B. Экспериментальные `cacheComponents` и `partialPrefetching` отключены: они несовместимы с явной динамичностью API авторизации и профиля B.
- Исправлен тип тестовой коллекции MongoDB в интеграционном тесте B; это устраняет ошибку TypeScript в текущем CI B3.

## Проверки

- `npm ci` и `npm run setup:local` из корня прошли; локальный `.env.local` создан со случайным секретом, внешняя доставка выключена.
- После подключения B4 и экранов A `npm run check` прошёл: ESLint, TypeScript, 82 unit-теста и production build. Запущенный production server вернул HTTP 200 для `/`, `/search`, `/stocks/AAPL`, `/login`, `/register`, `/settings`, `/api/health`. Для синтаксически неверного `/stocks/ZZZZINVALID` интерфейс показал страницу 404, хотя HTTP-статус ответа при потоковой отдаче Next.js был 200; проверку настоящего неизвестного тикера через рыночный API без MongoDB провести нельзя.
- `npm run test:integration` не дошёл до тестов: прокси ответил 403 на загрузку бинарника MongoDB 8.0.16 с `fastdl.mongodb.org`. Домен добавлен в черновик облачной конфигурации; требуется публикация настроек и повторная проверка доступа.

## Оставшиеся контракты

- Ветка B4 добавила защищённые HTTP-маршруты поиска, котировки, компании и новостей; она слита в эту ветку. Формы входа, профиля и дайджеста, поиск и карточка акции подключены к соответствующим API. Поиск использует задержку 350 мс и отменяет устаревшие запросы; UI различает отсутствие результата, ошибку квоты, истёкшую сессию и отказ сервиса.
- Сквозные сценарии с реальным локальным аккаунтом и MongoDB ещё не проверены из-за сетевого блока загрузки бинарника. Проверка API без MongoDB возвращает 503, как ожидается от отсутствующего обязательного сервиса; это не подтверждает работу авторизации или рыночных операций.
- Дашборд ещё не использует B API для котировок и новостей. График на карточке акции остаётся неподключённым: B API не предоставляет исторических свечей. Список отслеживания, правила и рассылка относятся к следующим этапам.
