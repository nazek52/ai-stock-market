# Интеграция интерфейса A с серверной основой B

Дата: 2026-10-14. Ветка: `feat/a-integration-root`. Основа: `stage-3/b-market-data`; история A0–A4 объединена merge-коммитом.

## Что объединено

- Единственное приложение Next.js теперь расположено в корне репозитория: экраны A перенесены в `src/app`, компоненты в `src/components`, справочные записи в `src/lib`. Серверные маршруты B в `src/app/api` сохранены.
- Зависимости интерфейса объединены с корневым `package-lock.json`. Настройки Tailwind/Turbopack совмещены с заголовками безопасности B. Экспериментальные `cacheComponents` и `partialPrefetching` отключены: они несовместимы с явной динамичностью API авторизации и профиля B.
- Исправлен тип тестовой коллекции MongoDB в интеграционном тесте B; это устраняет ошибку TypeScript в текущем CI B3.

## Проверки

- `npm ci` и `npm run setup:local` из корня прошли; локальный `.env.local` создан со случайным секретом, внешняя доставка выключена.
- `npm run lint`, `npm run typecheck`, `npm test` (76 тестов), `npm run build` прошли. Запущенный production server вернул HTTP 200 для `/`, `/search`, `/stocks/AAPL`, `/stocks/ZZZZINVALID`, `/login`, `/settings`, `/api/health`.
- `npm run test:integration` не дошёл до тестов: прокси ответил 403 на загрузку бинарника MongoDB 8.0.16 с `fastdl.mongodb.org`. Домен добавлен в черновик облачной конфигурации; требуется публикация настроек и повторная проверка доступа.

## Оставшиеся контракты

- Формы входа и профиля A требуют подключения к реализованным API B и согласования значений полей.
- Рыночный адаптер B3 пока не предоставляет HTTP-маршруты поиска, котировок и новостей. Экраны A продолжают явно показывать локальные справочные записи и недоступность живых данных.
- Для завершения P4.1 и P4.4 нужны серверный поиск, различимая ошибка квоты, debounce и отмена устаревших запросов. Для P3.3 и P4.3 нужны ответы адаптера с источником, валютой и временем данных.
