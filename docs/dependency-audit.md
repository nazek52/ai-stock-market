# Проверка зависимостей

Повторная проверка объединённой версии A+B, 2026-10-15: `npm audit --omit=dev --audit-level=high` — 0 известных runtime-уязвимостей. Полный аудит — 9 high-записей в dev-дереве: прежняя цепочка ESLint и добавленная A CLI-цепочка shadcn/ts-morph сходятся к тому же advisory braces. Это число затронутых пакетов, не девять разных первопричин. Непроверенные registry/glob-шаблоны не следует передавать этим инструментам. Автоматический downgrade Next.js/shadcn через `audit fix --force` не применялся; совместимое исправление остаётся отдельной задачей сопровождения.

Дата: 2026-10-14. Установка воспроизводится через `npm ci` и `package-lock.json`; версии Node и GitHub Actions зафиксированы в репозитории.

На этапе 1 `npm audit --omit=dev` не обнаружил известных уязвимостей runtime-зависимостей. Этот аудит включён в CI и должен повторяться после изменения lockfile.

Полный аудит выявляет цепочку dev-зависимостей `eslint-config-next -> fast-glob -> micromatch -> braces`. Для [GHSA-vfj7-8cjw-p6xm](https://github.com/advisories/GHSA-vfj7-8cjw-p6xm) пока нет исправленной версии. Уязвимость связана с глубоко вложенными glob-шаблонами; линтер получает только статические шаблоны из репозитория, пользовательские строки в него не передаются. В runtime эта цепочка не устанавливается. Не понижать Next.js до устаревшей версии ради автоматической команды `audit fix --force`; заменить зависимость, когда появится совместимое исправление.

Production-развёртывание дополнительно требует актуального аудита контейнера и реальной среды; локальный аудит пакетов его не заменяет.
