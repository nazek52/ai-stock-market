# Доработка дашборда A3 после контрактов B4/B5

Дата: 2026-10-14. Ветка: `feat/a-stage-3-dashboard-data` поверх A5. Исходный интерфейс A3 и виджеты TradingView сохранены; старые сообщения о неподключённых серверных источниках заменены на текущие защищённые API.

## Результат

- Блок котировок запрашивает AAPL, MSFT и NVDA через `/api/stocks/[symbol]/quote`. У каждой цены указаны валюта, источник и время котировки. Каждая строка имеет собственную загрузку, ошибку и повтор; отказ одного запроса не скрывает остальные или TradingView.
- Блок новостей читает `/api/stocks/AAPL/news`, показывает до пяти публикаций, дату и источник. В режиме `fixture` заголовки явно помечены синтетическими и не ведут на фиктивные ссылки.
- Компактный блок списка читает `/api/watchlist`, показывает до пяти последних сохранённых акций со ссылками на карточки и полный список. Цена здесь не подставляется без отдельного запроса.
- Для защищённых API предусмотрены состояния входа, квоты, отказа сервиса и отсутствия данных. Данные TradingView остаются независимым виджетом со своей подписью источника.

## Проверки и пределы

- `npm run check` прошёл: ESLint, TypeScript, 82 unit-теста и production build с маршрутом `/`.
- Локальная MongoDB ещё не запускается из-за сетевого 403 на `fastdl.mongodb.org`; сквозная проверка персональных данных, синтетических котировок и новостей с сессией ожидает применения настройки среды. Без MongoDB API возвращают 503.
- Визуальная проверка embed TradingView на телефоне остаётся открытой: предыдущая попытка headless Chromium завершилась по таймауту. Серверные HTML-маршруты и сборка проверяются отдельно.
