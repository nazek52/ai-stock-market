# Передача участника A: поиск и карточка акции этапа 4

Дата: 2026-10-14. Задачи: P4.1, P4.3, P4.4, P4.5. Статус: интерфейс и переходы реализованы на локальных справочных записях; сквозная приёмка ожидает серверный поиск и данные участника B.

## Результат

- `/search` фильтрует четыре явно обозначенные демонстрационные записи по тикеру или названию. Пустой запрос и отсутствие совпадений имеют отдельные состояния; результаты ведут на `/stocks/[symbol]`.
- Карточка известных записей показывает только справочные название и биржу. Цена, изменение, график, профиль, показатели и новости помечены недоступными до подключения проверенного источника. Неизвестный символ получает понятное состояние с возвратом к поиску.
- Из карточки доступен переход к разделу списка отслеживания. Добавление в список пока не активировано: защищённый API списка относится к следующему этапу.

## Границы реализации

- Локальный поиск не отправляет запросы, поэтому задержка ввода, отмена устаревших запросов и ограничение частоты P4.1 будут добавлены при подключении серверного поиска. Четыре записи не являются полным каталогом рынка.
- Состояние исчерпанной квоты P4.4 требует различимой ошибки от серверного API. Сейчас есть состояния отсутствия записи и недоступности данных.
- Нормализация и валидация символа, биржа и тип инструмента в серверном ответе относятся к P4.2 участника B. Текущая справочная карточка не подменяет этот контракт.
- Приложение A находится в `web/`, а серверная основа B в корне репозитория. Перед сквозной проверкой нужен один рабочий Next.js app и согласованные контракты.

- `npm run build`, `npm run lint`, `npx tsc --noEmit` из `web/` прошли. GET `/search`, `/stocks/AAPL`, `/stocks/ZZZZINVALID` вернули HTTP 200. `git diff --check` прошёл.
