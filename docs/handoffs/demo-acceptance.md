## Ограничения и следующий шаг

Показывать проект по `docs/local-demo.md`: Docker Desktop, `npm ci`, `npm run demo`. Данные сервера синтетические, AI детерминированный и не вызывает LLM; письма остаются в Mailpit. TradingView требует Интернета и не участвует в срабатывании правил. Настоящие Finnhub/Gemini/SMTP, биржевой календарь/лицензия, volume и публичный production — будущие расширения. Не обещать их наличие при показе.

Передано обоим участникам: A — сценарий и границы UI-приёмки в матрице; B — защищённый endpoint, журналы, восстановление и проверки. Для текущего показа новые аккаунты сервисов не нужны. Следующая отдельная необязательная работа — расширенная матрица адаптивности/доступности и обслуживание dev-зависимостей.
