## Изменённые файлы и интерфейсы

- `scripts/demo.mjs`, `.d.mts`, `package.json`, `tests/deployment/demo.test.ts`: одна команда запуска, отдельная демобаза, локальные сервисы и принудительные fixture-параметры. `.env.local` не перезаписывается, секреты и внешние ключи не печатаются.
- `src/components/auth/email-verification.tsx`, `src/app/settings/page.tsx`: подтверждение собственного адреса сессии и повторный запрос письма через Better Auth.
- `src/server/market/{fixtures,index}.ts`, `tests/market/client.test.ts`: поиск по общеизвестным названиям при сохранении меток синтетического источника.
- `src/app/demo/page.tsx`, `src/components/demo/alert-scenario.tsx`, `src/app/api/demo/scenario/route.ts`, `src/server/demo/scenario.ts`: защищённый локальный сценарий AAPL 99 → 101 через обычный движок правил, durable event и delivery journal. Один requestId не отправляет повторное письмо, временное правило удаляется.
- `src/server/alerts/worker.ts`: общий payload письма для фонового обработчика и сценария демо; семантика baseline/crossing/cooldown сохранена.
- `tests/integration/demo-scenario.test.ts`: ownership, origin, выключенный production endpoint, replay, quota, ошибки доставки и очистка.
- README, план Markdown/PDF, решения, локальное руководство и рабочие контракты отражают бесплатную локальную поставку. Удалён генерируемый Next.js блок AGENTS: в конфигурации уже отключена его генерация; правила владельца сохранены.

Новый API `POST /api/demo/scenario` принимает только `{requestId: UUID}`; userId берётся из сессии. Требует подтверждённого email. Доступен только с `LOCAL_DEMO=true`, вне production, при fixture market/AI, локальном SMTP Mailpit, отдельной БД с суффиксом `_demo` и выключенных расписаниях. Ответ содержит синтетические цены/счётчики/статус, не содержит адреса, токенов или секретов. Новый флаг задаётся launcher, не ослабляет production preflight.

## Ограничения и следующий шаг

Это локальная демонстрация. Рыночные данные синтетические, AI-сводка детерминированная, внешним адресатам письма не доставляются. TradingView — отдельный необязательный внешний виджет. Автоматические расписания выключены; `/demo` демонстрирует управляемое пересечение. Volume-above отложен. Live Finnhub/Gemini/SMTP и публичный deployment не заявляются проверенными и не блокируют локальную v1. Все оставшиеся обязательные проверки экранов доступны в руководстве; полный WCAG-аудит этим прогоном не заявляется.

Передано обоим участникам: запускать общую main через `npm run demo`, показывать список/настройки/правила и Mailpit по руководству. Новые задачи оформлять отдельными ветками от main. Секреты, тестовые пароли, токены и дампы БД в Git не добавлены.
