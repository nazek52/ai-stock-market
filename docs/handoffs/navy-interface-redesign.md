## Ручная проверка

40 измерений основных 10 маршрутов на 320/768/1440/720 px, дополнительно заполненные обзор/поиск/preview на трёх размерах, правило на 320 px и 12 вспомогательных auth/404/unsubscribe состояний. Собственный DOM без горизонтальных переполнений, неназванных controls и сломанных ARIA-ссылок в проверенных состояниях. Навигация отдельно проверена при фактических 320/390/520/522/768/1440 px; длинные подписи помещаются в controls.

Клавиатура: раскрытие восстановления Enter, фокус ошибок email/правила, поиск и очистка, Escape/отмена/подтверждение правила, прокрутка PRE сводки с видимым фокусом. Временное правило удалено, согласие на сводку восстановлено в false, AAPL сохранён. Пароли не менялись, POST-отписка в этом редизайне не выполнялась.

После финальной правки embed выполнены reload и клиентские переходы обзор → AAPL → обзор: графики загрузились, новых console errors не зафиксировано. Чистый перезапуск после build исключает старый dev CSS; финальный скриншот показывает тёмные графики и заполненные карточки. Локальные снимки/замеры — вне Git, адреса и подписанные токены в репозиторий не включены.

## Ограничения и следующий шаг

Реальное browser zoom 200/400%, screen reader и устройства отдельно не проверялись; 720 px — только дополнительный reflow. Reduced-motion подтверждён исходным CSS без переключения системной настройки. FPS не измерялся. Глобальный аварийный fallback просмотрен по коду; сторонние iframe не объявляются полностью доступными.

Передано A/B: локальную v1 можно показывать по [сценарию](../local-demo.md). Открытых зависимостей D6 нет. Облачные/live-интеграции и будущее публичное размещение сохраняют прежние границы плана.
