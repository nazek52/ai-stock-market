# Рабочий контракт участника B

Назначение владельца от 2026-10-14: реализовать серверную часть по плану v1.1 с субагентами, веткой для каждого этапа и небольшими проверенными коммитами. Автор Git: подтверждённый `Zaywoo66`; репозиторий: `nazek52/ai-stock-market`.

- Область: P0.2/P0.3, P1.3/P1.4, P2.1/P2.3, P3.3, P4.2, P5.1/P5.2, P6.1/P6.2/P6.3/P6.5, P7.2/P7.3/P7.4/P7.5, P8.2/P8.4.
- Интерфейс участника A: типизированные контракты `src/contracts` и описанные в `docs/api-contract.md` маршруты. Минимальная оболочка Next.js нужна для исполнения API; полноценные экраны остаются задачами A.
- Зависимости: внешних аккаунтов пока нет. Разработка и интеграционные проверки используют локальный MongoDB и синтетические данные. Реальные ключи вводятся только в игнорируемый `.env.local`.
- Разрешённые изменения: серверные модули, API, контракты, тесты, настройки сборки/CI/локального запуска и документация B.
- Критерии: изоляция пользователей, серверные секреты, валидация, ограничение запросов, повторяемость фоновых задач, отсутствие дублей и проверка сборки.
- Ветки: `stage-0/b-service-decisions`, затем `stage-1/b-foundation` и последующие `stage-N/b-*`. Пока изменения предыдущих этапов не объединены владельцем, ветки зависимые; основание каждой фиксируется в handoff.
- Проверки: lint, typecheck, unit-тесты, интеграционные тесты на отдельном MongoDB replica set, production build; реальные внешние проверки отмечаются отдельно.
- Коммиты/push: разрешены владельцем для завершённых частей. Автоматическое объединение в main и публичный deploy не требуются до проверки результата.
- Проверяющий: основной агент проверяет изменения субагентов; финальное подключение экранов принимает A.

Выполненный код и подтверждённый запуск внешнего сервиса являются разными статусами. P8.4 не считается завершённым до появления реальной среды, HTTPS и секретов.
