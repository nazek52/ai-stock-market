# P1.2 / P3.1 / P8.3 — чёрный интерфейс с navy blue

- Назначение: пользователь просит полное визуальное обновление существующего фронтенда, плавные анимации и отзывчивость.
- Ведущий: A (дизайн/доступность); B принимает интеграцию. Вход — main `dd99f11`, действующие API, предыдущий аудит P8.3 и принятые локальные D1–D5.
- Решение: единая тёмная тема независимо от темы ОС; почти чёрные поверхности, navy blue для акцентов/активных состояний, светлый текст, сдержанная глубина и согласованная типографика. Проверяемый результат важнее заявления об «идеальном» дизайне.
- Область: оболочка/стили/общие компоненты, обзор, auth/profile, поиск/акция/списки/правила, демо и служебные HTML-состояния. Серверные контракты, данные и облачные сервисы не меняются.
- Совместная работа: root владеет globals.css, layout, shell, ui, brand, обзором/market, demo и документацией; агент auth — auth/profile; агент workspace — stocks/watchlist/alerts и их page.tsx; агент fallback — error/global-error/not-found/loading и unsubscribe HTML. Один файл — один владелец.
- Приёмка: единые цвета и компоненты всех экранов, 320/768/1440 CSS px, видимый фокус и клавиатура, reduced-motion; без layout-анимаций тяжёлых графиков и без непрерывного JS-рендера. Проверить lint/типы/unit/build, затронутую интеграцию и браузер.
- Git: отдельная codex-ветка, последовательные тематические коммиты и публикация результата с CI по ранее разрешённому пользователем workflow. Публикация облачного приложения не входит.
- Handoff: `docs/handoffs/navy-interface-redesign.md`.
