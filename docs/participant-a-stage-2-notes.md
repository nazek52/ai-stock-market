# Передача участника A: предпросмотр настроек этапа 2

**Задачи:** P2.2 и P2.5, только интерфейс. **Статус:** частично — серверный контракт профиля, сессия и сохранение ещё не подключены.

На `/settings` доступны поля страны, цели, допустимого риска, отрасли, часового пояса IANA и согласия на ежедневный email. Подписка изначально выключена. Форма явно помечена как предпросмотр: ввод не сохраняется, письма не отправляются, кнопка сохранения отключена. При нажатии Enter форма не отправляет данные в URL.

Значения выпадающих списков пока являются предложением интерфейса. Участнику B нужно согласовать допустимые значения `goal`, `risk`, `sector`, формат страны, проверку IANA-пояса, серверные ошибки и отдельное хранение согласия до подключения операции сохранения. A затем добавит загрузку сохранённого профиля, клиентскую валидацию по согласованной схеме, отправку и доступные сообщения об ошибке/успехе. Серверная операция должна определять пользователя по сессии и проверять права самостоятельно.

**Изменено:** `web/src/app/settings/page.tsx`, `web/src/components/profile/profile-settings-preview.tsx`.

**Проверки:** `npm run lint`, `npx tsc --noEmit`, `npm run build`, `git diff --check` прошли; GET `/settings` вернул HTTP 200 и ожидаемые подписи. Первый запуск `npm run build` столкнулся с параллельной сборкой, повтор после её завершения прошёл.
