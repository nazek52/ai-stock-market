# Передача участника A: предпросмотр форм этапа 2

**Задачи:** P2.2, P2.4 и P2.5, только интерфейс. **Статус:** частично — серверный контракт профиля, авторизация, сессия и сохранение ещё не подключены.

На `/login` и `/register` доступны формы входа и регистрации с подписями, проверкой обязательных полей, формата email и совпадения паролей. Ошибка связывается с полем, фокус переходит к первой ошибке. Валидная отправка явно сообщает, что данные не отправлены и сессия не создана. Восстановление доступа и обработка серверных ошибок ожидают решения B по P2.1/P2.3 и согласованного объёма P2.4.

На `/settings` доступны поля страны, цели, допустимого риска, отрасли, часового пояса IANA и согласия на ежедневный email. Подписка изначально выключена. Форма явно помечена как предпросмотр: ввод не сохраняется, письма не отправляются, кнопка сохранения отключена. При нажатии Enter форма не отправляет данные в URL.

Значения выпадающих списков пока являются предложением интерфейса. Участнику B нужно согласовать допустимые значения `goal`, `risk`, `sector`, формат страны, проверку IANA-пояса, серверные ошибки и отдельное хранение согласия до подключения операции сохранения. A затем добавит загрузку сохранённого профиля, клиентскую валидацию по согласованной схеме, отправку и доступные сообщения об ошибке/успехе. Серверная операция должна определять пользователя по сессии и проверять права самостоятельно.

**Изменено:** `web/src/app/login/page.tsx`, `web/src/app/register/page.tsx`, `web/src/components/auth/auth-form.tsx`, `web/src/app/settings/page.tsx`, `web/src/components/profile/profile-settings-preview.tsx`, навигация в `web/src/components/app-shell.tsx` и её мобильный стиль.

**Проверки:** `npm run lint`, `npx tsc --noEmit`, `npm run build`, `git diff --check` прошли; GET `/settings` вернул HTTP 200 и ожидаемые подписи. Маршруты `/login` и `/register` вошли в production-сборку. Первый запуск `npm run build` столкнулся с параллельной сборкой, повтор после её завершения прошёл.

**Получатель:** участник B — согласовать данные, операции, ошибки и восстановление доступа; участник A — подключить формы после handoff B и проверить два тестовых аккаунта. Коммиты см. в истории ветки `feat/a-stage-2-profile-forms`; PR пока не создан из-за недоступности GitHub API.
