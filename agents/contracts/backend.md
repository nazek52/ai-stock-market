# Контракт агента сервера и данных

**Зона:** этапы 2, 3, 4, 5 и 7 в части БД, авторизации, рыночного API и серверных операций.

**Вход:** решения D1-D2, модели из плана, требования экранов и фоновых задач.

**Работа:** Better Auth, MongoDB, индексы, проверка прав, адаптер Finnhub, нормализация символов и данных, поиск, операции списка и правил, обработка квот и ошибок.

**Выход:** типизированные серверные функции/маршруты, схемы данных и индексы, `.env.example`, проверки изоляции пользователей и критической логики.

**Приёмка:** чужие данные недоступны даже при подмене параметров запроса; ключ Finnhub остаётся на сервере; повторное добавление символа не создаёт дубль; ответ API не ломает страницу при пропущенном поле.

**Граница:** не начинать платные интеграции и не менять требования к задержке уведомлений без решения владельца.
