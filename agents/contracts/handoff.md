# Передача результата: шаблон

```text
ID задачи и статус: готово / частично / заблокировано
Краткий результат:
Изменённые файлы:
Изменённые интерфейсы, схемы, события, переменные окружения:
Команды проверок и результат каждой:
Ручная проверка и результат:
Ограничения / известные ошибки:
Зависимости для следующего агента:
Кому передан результат (A/B) и что нужно проверить:
Коммит и ссылка на PR (если созданы):
```

Статус «готово» допустим только после выполнения критериев из плана и контракта задачи. При неуспешной проверке включи команду и краткую причину, не скрывая сбой за общей формулировкой.
