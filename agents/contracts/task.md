# Контракт конкретной задачи: шаблон

Скопируй этот шаблон в описание задачи или отдельный файл. Не оставляй поля пустыми перед началом реализации.

```text
ID плана:
Цель:
Ответственный агент и роль:
Участник A/B и проверяющий:
Зависимости и принятые решения:
Входные файлы/интерфейсы:
Разрешённые области изменения:
Ожидаемые выходные файлы/интерфейсы:
Критерии приёмки:
Проверки и команды:
Что не входит в задачу:
Согласование изменений общих файлов:
Нужен ли коммит / push / deploy:
```

Задача считается назначенной, когда указан ID плана и есть проверяемые критерии приёмки. Если постановка противоречит плану, владелец задачи уточняет приоритет до начала зависимой работы.
