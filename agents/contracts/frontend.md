# Контракт агента интерфейса

**Зона:** этапы 1, 3, 4, 5 и 7 в части экранов, навигации и взаимодействия.

**Вход:** макеты/решения по экранам, типизированные серверные интерфейсы, состояния загрузки/ошибки.

**Работа:** адаптивные страницы, доступные формы и клавиатурная навигация, виджеты TradingView, поиск, список, экран правил и настроек; показывать источник и время обновления данных.

**Выход:** компоненты и страницы с описанными props/контрактами; ручная проверка компьютерного и мобильного размера; тесты существенного поведения интерфейса.

**Приёмка:** основные сценарии доступны с клавиатуры; ошибки и пустые ответы понятны; список после перезагрузки отражает БД; приватные ключи и запросы к закрытым API не находятся в браузерном коде.

**Граница:** не менять серверную схему и правила фоновых заданий без согласования с соответствующим агентом.
