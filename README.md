# AI Stock Market

Репозиторий для разработки приложения наблюдения за фондовым рынком по мотивам [видеоурока JavaScript Mastery](https://youtu.be/gu4pafNCXng).

Здесь находятся спецификация проекта и начальный каркас интерфейса. Функции приложения будут добавляться по этапам.

## Каркас интерфейса

В папке `web/` находится интерфейс Next.js для задач участника A. Дашборд подключает публичные виджеты TradingView; собственные котировки Finnhub, авторизация и пользовательские операции ещё ожидают серверной реализации. Страницы показывают это явно и не выводят фиктивные котировки.

Для локального запуска нужен Node.js 20.9 или новее. Выполните в `web/`:

```bash
npm ci
npm run dev
```

Откройте `http://localhost:3000` для локальной проверки. Для проверки изменений выполните `npm run build`, `npm run lint` и `npx tsc --noEmit` в той же папке. Необходимые для серверных функций переменные окружения и сервисы будут определены в задачах участника B.
