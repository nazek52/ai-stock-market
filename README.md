# AI Stock Market

Бесплатный учебный проект двух участников по мотивам [видеоурока JavaScript Mastery](https://youtu.be/gu4pafNCXng): биржевой интерфейс, аккаунт, поиск, личный список, сводка и правила уведомлений в одном Next.js-приложении.

Репозиторий: https://github.com/nazek52/ai-stock-market. **A** отвечает за интерфейс, пользовательские сценарии и доступность; **B** - за сервер, БД, API и фоновые задания. Общая версия объединяет историю этапов обоих участников в main. Подробности совместной проверки: [handoff интеграции](docs/handoffs/integration-ab-local-demo.md). Форматы данных и ошибки: [контракты API](docs/api-contract.md).

## Быстрый запуск демо

Нужны Node.js 24 LTS и запущенный Docker Desktop с Linux-контейнерами. Не нужны аккаунты Finnhub, Gemini, Inngest Cloud, почтового провайдера или платный хостинг. Интернет потребуется при первой установке пакетов и загрузке Docker-образов.

```sh
npm ci
npm run demo
```

Откройте приложение [localhost:3000](http://localhost:3000), локальные письма [Mailpit](http://127.0.0.1:8025) и задания [Inngest Dev](http://127.0.0.1:8288). Команда готовит сервисы, создаёт .env.local при отсутствии и запускает приложение с отдельной демобазой ai_stock_market_demo. Существующий env-файл не перезаписывается; безопасные параметры демо задаются окружением запуска.

Если порт 3000 занят, используйте `npm run demo -- --port 3100` и откройте адрес из терминала. Скрипт сообщает о занятом порте и не завершает чужие процессы. Ctrl+C останавливает свой Next.js; общие контейнеры остаются работать. Для остановки сервисов: `npm run services:down` (данные MongoDB сохраняются).

Проверка за несколько минут: зарегистрироваться с вымышленным адресом demo@example.test, открыть письмо в Mailpit, подтвердить адрес, найти AAPL или Apple, добавить акцию в список, открыть настройки и preview сводки, создать правило цены. На `/demo` отдельно отправьте сводку в Mailpit и проверьте повтор без дубля; затем запустите синтетическое ценовое событие. В письме сводки есть ссылка подтверждения отписки; открытие ссылки само по себе рассылку не выключает. Подробный [сценарий демонстрации](docs/local-demo.md) объясняет доступные данные и проверку уведомлений. Вход и проверка прав работают и в деморежиме.

## Что показывает демо

Котировки, компании и новости - собственный **синтетический набор** с меткой fixture. Реальные названия используются как поисковые псевдонимы. Локальный режим AI детерминированно собирает заголовки выбранных новостей; он **не вызывает Gemini и не является результатом работы языковой модели**. Все письма перехватывает Mailpit, они не уходят внешним получателям. Автоматические дайджесты и ценовые обходы выключены по умолчанию.

TradingView-виджеты - дополнительный внешний контент: им нужен Интернет, но не сервисный аккаунт приложения. При недоступности виджетов поиск, список и собственный сервер продолжают работать. Облачные адаптеры Finnhub/Gemini/SMTP сохранены для будущего расширения; они не требуются для приёмки локальной v1.

Ручной запуск и альтернативы Docker описаны в [local-services.md](docs/local-services.md). Обычный `npm run dev` использует ваш .env.local; принудительная демоконфигурация применяется только к `npm run demo`.

## Проверки

```sh
npm run check
npm run test:integration
```

check запускает lint, TypeScript, unit-тесты и production build. Интеграционные тесты поднимают собственный временный MongoDB replica set, Docker им не нужен. Тестовая БД не использует .env.local и не должна указывать на настоящую БД. /api/health - liveness; /api/readiness проверяет writable replica set и возвращает 200/503. Эти проверки не заменяют ручной прогон экранов и Mailpit; результаты и ограничения фиксируются в handoff.
